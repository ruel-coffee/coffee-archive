# DIAL IN°

레시피를 따라 추출하고, 모든 변수를 기록하고, 한 잔의 차이를 함께 토론하는 커피 커뮤니티의 인터랙티브 웹 프로토타입입니다.

## 이번 프로토타입에 포함된 것

- 교체 가능한 중앙 모션 영상 쇼룸
- 4:6 / One Cup V60 / Three Pour 가이드 타이머
- 단계 전환 소리와 진동 알림
- 물, 장비, 날씨, 디게싱 등 기록 필드 켜기·끄기 및 사용자 필드 추가
- 브루 기록 저장, 조회, JSON 내보내기
- 커뮤니티 피드, 좋아요, 공유, 새 토론 작성
- 로스터 브랜드의 디게싱 로그 콘셉트
- 데스크톱과 모바일 반응형 레이아웃
- `prefers-reduced-motion` 접근성 대응

현재 기록과 커뮤니티 글은 브라우저의 로컬 저장소에 보관됩니다. 정식 버전에서는 기존 저장소의 Supabase 구성을 연결해 계정별 동기화와 실제 커뮤니티 데이터로 확장할 수 있습니다.

## 실행

별도 설치 없이 `index.html`을 열거나 정적 서버로 실행하면 됩니다.

```bash
python3 -m http.server 4173
```

그 다음 `http://localhost:4173`을 엽니다.

## 파일

- `index.html` — 페이지 구조와 콘텐츠
- `styles.css` — 비주얼 시스템, 반응형 레이아웃, 모션
- `app.js` — 타이머, 기록, 아카이브, 커뮤니티 상호작용

## 디자인 방향

무채색 쇼룸, 스위스 그리드, 큰 타이포그래피, 절제된 마이크로 인터랙션을 기반으로 했습니다. 영상과 모션은 기능보다 앞서지 않도록 핵심 행동인 “추출 시작”과 “기록”을 중심에 두었습니다.
